## 다음에 쓸 돈·시간의 순서

   파이프라인 수준에서 종료 -- 4단계도 돌릴 이유가 없다.

   (`data/live_STOP` 삭제, `--paper` 제거). 전진 게이트 7개 통과가 재개 조건.
3. LLM 판정 729일 $256 은 **보류**. 1단계가 "텍스트는 수치 위에 +0.011" 로 끝나 LLM 필드가
   그보다 나을 근거가 없다. 2·3단계가 살고 4단계가 텍스트 기여를 요구할 때 다시 본다.
4. 수량 램프(1주→N주 체결 모형)는 우위가 확인된 뒤의 별도 연구. 1주 × 5종목은 우위가
